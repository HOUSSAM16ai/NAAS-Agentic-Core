## Agent truth rules

The context system is **ACTIVE as a governance and navigation layer**. It does not mean that every external repository has been copied, every criterion has been implemented, or every commercial offer has revenue. The adoption matrix distinguishes mandatory references, active standards, seams, absent references, and pending classification.

A source in `PENDING_CLASSIFICATION` is known to exist and is not ignored, but its purpose, license, security implications, and local application must be reviewed from the primary source before any new adoption. A source in `EXTERNAL_ABSENT` remains explicitly absent; it cannot be activated by a prompt, a branch, or a model-generated suggestion.

## Completion evidence for each source card

A source card is complete only when it records the source purpose, the local principle or criterion, the local application path, the enforcer, a test or evidence path, the accountable owner, the runtime boundary, and the upgrade condition. The matrix is the index; source-specific implementation evidence remains in the local files named by each card.

## Commercial truth

The project’s commercial objective is foreign-currency revenue, but all seven catalog entries remain `PROPOSED` until contracts, payments, subscriptions, or other verifiable customer evidence are recorded. No agent may convert a reference, prototype, research note, or GitHub popularity count into a revenue claim.
