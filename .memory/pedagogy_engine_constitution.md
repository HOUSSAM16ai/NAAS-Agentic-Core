## 1. التشخيص الدستوري (لماذا هذا الدستور وُلد)

> **«النظام ليس «Chatbot تعليمي» — لكن لا أحد يهتم إذا قلنا 'نظامنا أكثر ذكاءً'.
> نبدأ امتلاك شركةٍ حقيقيةً فقط عندما نقول: الطلاب الذين استخدموا Pedagogy Engine
> حققوا +X% تحسّنًا في الاحتفاظ والفهم مقارنةً بمجموعةٍ ضابطة.»**

الفجوة المقيسة بين الأرقام (8.5–9/10 فكرةً · 3.5–4.5/10 منتجًا مثبتًا) هي بالضبط
العمل الذي يفرضه هذا الدستور. لا محاولة إضافة 100 ميزة جديدة — الأولوية تجربة
واحدة خارقة تثبت أن النظام **يكتشف خطأً معرفيًا لا يكتشفه Tutor عادي، ثم يختار
تدخّلًا يؤدي إلى تعلّمٍ أفضل قابلٍ للقياس.**

### 1.1 الأعداء الدستورية الثلاثة (قواعد سلبية دائمة — لا تُكسر)

1. **عدو #1: «مجرّد Prompt 'كن مدرسًا جيدًا'»** — لا قرار تربوي صحيح من صياغةٍ أذكى.
2. **عدو #2: «الإجابة الصحيحة ≠ الإجابة التربوية»** — الملاءمة التربوية تعتمد على
   استعداد الطالب، وتسلسل المنهاج، وتوقيت تقديم المفهوم (أدبيات 2026) — والحيرة
   لا تُهنَّأ (يمتدّ D-208).
3. **عدو #3: «وَهْم الطلاقة» (Fluency Illusion، يمتدّ roadmap §1)** — الأداء اللحظي
   (recognition) ليس التعلّم الدائم (generation، Bjork). كل مقياسٍ يقيس الرضا
   أو التفاعل اللحظي مقياسٌ مضلّل دستوريًا (§6).

## 2. العقيدة الأساسية: العقل التربوي يقرّر (The Pedagogical Decision Engine)

اللعبة ليست «AI أقوى من ChatGPT» — شبه مستحيل وغير ضروري. القاعدة الدستورية:

> **«نستخدم أقوى النماذج الموجودة كطبقة ذكاء، ونبني فوقها نظامًا متخصصًا في
> تشخيص التعلّم واتخاذ القرار التربوي.»**

ChatGPT/Claude/Gemini/OpenRouter = **المحرك اللغوي (بنية تحتية لنا)**.
النظام = **العقل التربوي الذي يقرّر ماذا يجب أن يحدث للمتعلم.**

كل رسالةٍ من الطالب تدخل **حلقة القرار التربوي** (لا «طالب يسأل → LLM يجيب»):

```
Student Utterance
→ Model the learner state    (ماذا يعرف؟ ماذا يظن أنه يعرف؟ — Learner Model)
→ Diagnose the error         (أين الخلل؟ ما نوع الخطأ؟ لماذا أخطأ؟)
→ Select strategy            (ما الاستراتيجية التي تنجح مع هذا الطالب الآن؟)
→ Intervene                  (تشخيصي / مثال مصغّر / تلميح / خطوة / منع dump)
→ Test understanding         (برهان توليد لا برهان اسم — الحيرة لا تُهنَّأ، D-208)
→ Observe change             (هل تغيّر النموذج المعرفي؟ بأيّ حجم؟)
→ Update learner model       (BKT/DKT + ذاكرة طويلة الأمد)
→ Re-plan path               (المسار يُعاد بناؤه من الأثر لا من التخمين)
→ Report Learning Gain       (قياسٌ أمام مجموعةٍ ضابطة — §6)
```

**الفصل الدستوري (يمتدّ pedagogical_os.md §3):** الـ LLM **للسرد والفهم والتشخيص
اللغوي فقط**. لا يحسب حقائقٍ رياضية (Symbolic Truth، D-153)، ولا يقرّر الإتقان
(`mastery` قرارٌ إحصائي على `student_mastery_probability` — BKT/DKT — لا إعجاب
بالنص)، ولا يقيس التعلم (قياسٌ رمزي/إحصائي لا اقتناع لغوي).

## 3. الركائز الأربع للـmoat (الأبواب الدستورية — كل بابٍ له حارس)

### الباب الأول: النموذج المعرفي للمتعلم (Learner Model — ISS-174)

النظام **يجب** أن يعرف عن كل طالب ستة أشياء: ماذا يعرف؟ ماذا يظن أنه يعرف؟
أين الفجوة؟ لماذا أخطأ؟ ما نوع الخطأ (جهل · ارتباك · اعتقاد خاطئ · اندفاع)؟
وما الاستراتيجية التي تنجح معه؟

- **المكوّن الحي الحالي:** `TutorState` (D-142) + BKT ثنائي القناة (D-126) +
  `UnderstandingStateSkill` (D-135) + `illusion_gap`.
- **القيد:** `illusion_gap` ليس «إتقانًا» — الفارق بين الأداء والقدرة الحقيقية
  هو المقياس الدستوري (P-D). **ممنوع** عرض رقم «إتقان» بلا فجوة وهمٍ بجانبه.

### الباب الثاني: ذاكرة التعلّم طويلة الأمد (Long-Term Learning Memory — ISS-175)

ليس «ماذا قال الطالب في آخر رسالة؟» بل **«كيف تغيّر الطالب خلال 6 أشهر؟»**:
Knowledge Tracing حقيقي (BKT موجود · DKT مخطَّط roadmap) + انحناء النسيان
(FSRS-5 · D-194 · D-229) + الاعتقادات الخاطئة المسجَّلة في `semantic_property`.

- **القيد:** لا تتبّع عميق قبل بياناتٍ ضخمة (D-229) — الذاكرة الطويلة تُبنى
  فوق ما يُحسب لا فوق ما يُخمَّن.

### الباب الثالث: محرك القرار التربوي (Pedagogical Decision Engine — ISS-176)

تسلسل حتمي: **تشخيص ← اختيار استراتيجية ← تدخّل ← قياس ← تحديث النموذج ←
تدخّل جديد**. كل تدخّلٍ **يُسجَّل قرارُه وسببُه** (`pedagogical_trace`):
لماذا هذه الاستراتيجية لهذا الطالب في هذه اللحظة؟ — القرار التربوي قرارٌ قابل
للتدقيق، لا معجزة صندوق أسود.

- **المكوّن الحي الحالي:** `PedagogicalPolicyEngine` (D-144) + السُّلّم الخماسي
  (D-104) + مصفوفة التصعيد + `_build_diagnostic_probe` (D-155).
- **القيد:** لا إعادة كتابة القرار التربوي كـprompt؛ الـprompt يُنفِّذ قرارًا
  اتخذته آلة القرار.

### الباب الرابع: إثبات Learning Gain (القفل الدستوري — ISS-177)

**أهم نقطة على الإطلاق.** قبل أي ادّعاء تسويقي أو منتج:

1. مقياسٌ **موحَّد قابل للتكرار**: pre-test ← تدخّل ← post-test ← follow-up
   متأجّل (retention — التعلّم الحقيقي يُقاس لاحقًا لا فورًا، Bjork).
2. مجموعةٌ ضابطة أو خط أساسٍ مقيس (المقارنة الدستورية الوحيدة المقبولة).
3. النتيجة تُعرض **بفجوة الوهم** (P-D): تحسّن القدرة غير المدعومة، لا الرضا.

- **القيد الأحمر:** ⛔ ممنوع قانونًا عرض «+X%» أو «تحسّن» على أولياء قاصرين
  بلا منهجيةٍ مقيسةٍ منشورة في `.memory/pedagogy_engine_truth.md` — حدّ
  المصداقية (D-227) يمتدّ إلى كل مقياسٍ تربوي.

## 5. الأسئلة الدستورية (وأجوبتها المُلزِمة)

| السؤال الدستوري | الجواب المُلزِم |
|---|---|
| هل نحارب ChatGPT؟ | **لا.** نستخدمه (وغيره عبر OpenRouter) كطبقة ذكاء ونبني العقل التربوي فوقه — هذا هو الفرق الاستراتيجي كله |
| أين الميزة التنافسية (moat)؟ | Diagnosis ← Adaptation ← Intervention ← Measurement ← **Learning Gain المقيس أمام ضابطة** — لا في LangGraph/Agents/خدمات |
| ما المعيار الأعلى للقرار التربوي؟ | **التعلّم الدائم** (توليد مستقل بعد أسابيع) — لا الرضا اللحظي ولا الأداء المدعوم |
| ماذا يحدث عند تعارضٍ ظاهري مع دستورٍ أقدم (D-153/D-144/D-208)؟ | التفسير في ضوء القوانين العشرة أعلاه — وكل دستورٍ قديم يبقى ساريًا بلا نقصٍ؛ هذا الدستور يعلوها في نطاق التعلّم المقيس |
| متى يجوز ادّعاء Learning Gain؟ | فقط بعد نشر المنهجية والبيانات في `.memory/pedagogy_engine_truth.md` وتجاوز حدّ المصداقية (D-227) |
| من يحرس هذا الدستور؟ | `check_pedagogy_engine.py` (قانون) + البوّابات المورَّثة (§4) + بوابة CI إلزامية |

## 6. مقياس النجاح الدستوري (لا يُعرض إلا مقيسًا — §4 الباب الرابع)

المتغيّرات الواجبة في أي تقييمٍ تعليمي حقيقي:

| المتغيّر | التعريف المقيس |
|---|---|
| **Diagnosis Accuracy** | نسبة أخطاءٍ شُخِّصت بنوعها الصحيح (جهل/ارتباك/اعتقاد خاطئ) مقابل تدقيقٍ يدوي |
| **Intervention Effect** | فرق الأداء قبل/بعد التدخّل على وحدةٍ مكافئة |
| **Retention** | أداءٌ متباعدٌ (3–14 يومًا) — التعلّم الحقيقي يُقاس لاحقًا |
| **Illusion Gap** | الأداء المدعوم − القدرة غير المدعومة (D-144/P-D) — يتقلّص لا يتوسّع |
| **Control Baseline** | خط أساسٍ مقيس أو مجموعة ضابطة — الادّعاء بلاها ممنوع (§4) |

**الجملة الدستورية الختامية:**

> **«ننتقل من «منصة تعليمية تستخدم AI» إلى «Learning Intelligence Platform»
> حين يثبت، مقيسًا وقابلًا للتكرار، أن النظام يكتشف ما لا يكتشفه Tutor عادي
> ويتدخّل بما يُحسِّن التعلّم فعلًا — لا انطباعًا.»**
