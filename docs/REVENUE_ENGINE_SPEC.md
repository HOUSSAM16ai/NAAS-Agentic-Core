## D-212) `shared/illusion/` — محرّك فجوة الوهم

> الوحدة التي تحوّل عقيدة `§0.6` من دالّة هدفٍ داخلية إلى **منتجٍ يُباع**. ✅ **مبنيّة.**

### النموذج الرياضي

**① الثقة المُعلَنة** — تُلتقط بضغطةٍ واحدة **قبل** الإجابة (بعدها تتلوّث بالنتيجة).
القيم مراكز فئات أحكام التعلّم (JOL) في أدبيات Nelson & Narens، وتُعاد معايرتها لاحقاً
من البيانات نفسها.

**② الإتقان الدائم غير المدعوم** — وهو **ليس** `P(L)` الخام من BKT (الخام يشمل محاولاتٍ
بتلميحٍ وبلا تأخير، وهو بالضبط ما يُنتج الوهم):

```
M_c = durable(c)  ×  R(Δt, S_c)
```

حيث `R` قابلية الاسترجاع من FSRS-5 القائمة (`shared/scheduling/fsrs.retrievability`).
**الضرب في `R` مقصود: مفهومٌ أُتقن قبل شهرٍ ولم يُراجَع ليس مُتقناً اليوم** — وهذا بالضبط
ما ينهار يوم الامتحان.

**③ الفجوة:** `gap_c = conf_c − M_c ∈ [−1, +1]`.

### التصنيف الرباعي — وهو المخرَج التجاري

|  | `M_c` مرتفع | `M_c` منخفض |
|---|---|---|
| **`conf` مرتفعة** | 🟢 **مُتقَن** — لا تُضِع وقتاً | 🔴 **وهمٌ خطر** — يعرف خطأً، وهذا ما يُسقِط |
| **`conf` منخفضة** | 🔵 **مهارة مخفيّة** — يحتاج ثقةً لا تعليماً | 🟠 **فجوة معلومة** — الحالة السهلة |

الخانة الحمراء هي المنتج: وليٌّ يرى ابنه «واثقاً ومخطئاً في مفاهيم عالية المعامل» يفهم
القيمة في ثلاث ثوانٍ، بلا شرحٍ وبلا معرفةٍ بالذكاء الاصطناعي.

**مؤشّر واحد للوليّ:** `IGI = Σ w_c · max(0, gap_c) / Σ w_c`، و`w_c` من
`shared/curriculum.exam_weight` (معامل المادة × تواتر الظهور). ⛔ **لا مصدر ثانٍ للأوزان.**
ونأخذ `max(0, gap)` لأن المهارة المخفيّة ليست وهماً يُخصَم منه — متوسّطٌ يجمع الاتجاهين
يُظهر طالباً واثقاً ومخطئاً في نصف المنهاج «معتدلاً».

### العقد

```python
# shared/illusion/model.py — stdlib فقط
class Quadrant(StrEnum):
    MASTERED = "mastered"        # 🟢
    DANGEROUS = "dangerous"      # 🔴  ← المنتج
    HIDDEN_SKILL = "hidden_skill"# 🔵
    KNOWN_GAP = "known_gap"      # 🟠

@dataclass(frozen=True, slots=True)

    concept_id: str          # من shared/curriculum — لا مصدر ثانٍ
    confidence: float        # [0,1] مُعلَنة
    durable_mastery: float   # [0,1] غير مدعومة × R(Δt,S)
    gap: float

    observations: int        # عدد المحاولات غير المدعومة

MIN_OBS = 4   # دون ذلك: لا تصنيف. الجهل يُعلَن جهلاً.
```

### القاعدة التي تحمي المصداقية

```python
if unaided_observations < MIN_OBS:
    return None      # لا Quadrant، لا لون، لا ادّعاء
```

⛔ **لا يُرجَع «مُتقَن» بملاحظتين.** على سابقة `shared/analytics/retention.py` حرفياً:
*«نُرجِع `None` لا صفراً — صفرٌ يقرأ فقدناهم والحقيقة لم يحن الوقت»*. والمبدأ نفسه:
**تقريرٌ يلوّن كلّ المنهاج بعد جلستين تقريرٌ كاذب**، والوليّ الذي يكتشف ذلك لا يجدّد.

### المقاييس


**الفارض:** `check_revenue_doctrine` (بند `MIN_OBS` وفحص النضج في كل مسارٍ يُنتج تصنيفاً)

## D-213) `shared/items/` — بنك العناصر المُعايَر

> **الأولوية المطلقة.** بلا هذه الوحدة: D-212 لا يقيس على عناصر، وD-216 لا يتوقّع،
> والعرض الحيّ يفشل.

### النموذج: Elo آنيّ لا IRT دفعيّ

تقدير المعالم بالإمكان الأعظم يحتاج مئات الاستجابات لكل عنصر **قبل** أن يُنتج شيئاً؛
و‏Elo يُنتج تقديراً مفيداً من الاستجابة الأولى ويتحسّن باستمرار (Klinkenberg et al., 2011).

```
E   = 1 / (1 + exp(−(θ_s − b_i)))       # الاحتمال المتوقّع
θ_s ← θ_s + K_θ · (S − E)               # قدرة التلميذ
b_i ← b_i − K_b · (S − E)               # صعوبة العنصر
K   = K₀ / (1 + n / n₀)                 # معامل يتناقص بعدد الملاحظات
```

المعامل المتناقص ضروري: عنصرٌ رأى مئات الاستجابات يجب ألّا تزحزحه استجابةٌ واحدة، وتلميذٌ
جديد يجب أن يستقرّ تقديره بسرعة.

### العقد

```python
@dataclass(frozen=True, slots=True)
class Item:
    item_id: str
    concept_id: str            # من shared/curriculum — إجباري
    subject: str               # من السجلّ، لا سلسلة حرّة
    stream: str
    session_year: int | None
    statement_md: str
    steps: tuple[Step, ...]    # ← ليست فارغة أبداً
    barem_nodes: tuple[str,...]# مراجع إلى D-214
    difficulty_b: float
    discrimination_a: float
    observations: int
    is_calibrated: bool
```

### الدرس المُستخلَص من التدقيق الداخلي

ثلاثٌ من مشاكل تدقيق `2026-05-21` تُحَلّ بقيد قاعدة بيانات لا بشيفرة — تُسجَّل في
`app/core/db_schema_config.py:REQUIRED_SCHEMA` (D-074: المخطّط يُنشأ عند الإقلاع، لا
بتشغيل SQL من الصندوق الرملي):

```sql
steps_json   JSONB NOT NULL CHECK (jsonb_array_length(steps_json) > 0),  -- لا فراغ
content_hash TEXT  NOT NULL UNIQUE,                                      -- لا تكرار
concept_id   TEXT  NOT NULL REFERENCES curriculum_concepts(id)
```

`content_hash` وحدها تمنع الكارثة الموثَّقة: **نفس التمرين ثلاث مرّاتٍ بثلاثة مُعرَّفات**.
والقيد على `steps_json` يمنع البند الموثَّق: *«النظام لا يستطيع تقديم الحل خطوة بخطوة»*.

### بوّابة التغطية — وهي التي تحسم مسألة العرض الحيّ

`check_item_coverage`: لكل (مفهوم × شعبة) في `shared/curriculum`، إن كان عدد العناصر دون
الحدّ الأدنى المُعلَن ⇒ CI أحمر مع اسم المفهوم الناقص. تحوّل «هل يحتمل البنك سؤالاً
عشوائياً؟» من قلقٍ إلى **إجابةٍ يعطيها CI**.

### هدف التغطية — بترتيب المعامل لا الراحة

**علوم الطبيعة والحياة أولاً** (معاملها الأعلى في الشعبة العلمية)، ثمّ الرياضيات، ثمّ
الفيزياء. والسبب مضاعف: معاملها الأعلى، **و**`classify_concept` كانت تُسقِط مفاهيمها
كلّها إلى `"general"` قبل D-193 — أي أنّ أثمن مادّةٍ في الشعبة كانت غير مقيسةٍ أصلاً.

**ما لا يجوز ادّعاؤه.** لا «بنك أسئلة ذكي». بل: *«N عنصراً، منها M معايَرة على عددٍ كافٍ
من الاستجابات، والباقي بصعوبةٍ مُقدَّرة تصريحياً ومُعلَّمة كذلك.»*

**الفارض:** `check_revenue_doctrine` اليوم؛ و`check_item_coverage` عند البناء.

## D-214) `shared/scoring/barem.py` — التصحيح وفق السلّم الرسمي

> الأصل الأكثر محلّية في المنتج كلّه. لا يُشترى بالمال ولا يُنسَخ من الخارج.

### النموذج: السلّم رسم بياني، لا قائمة

خطأ التصميم الشائع تمثيل السلّم كقائمة `(خطوة → نقاط)`. والواقع الجزائري أعقد، وفيه قاعدة
**لا تُعاقَب على الخطأ نفسه مرّتين**: تلميذٌ أخطأ في حساب المشتقّة ثمّ درس اتّجاه التغيّر
**صحيحاً انطلاقاً من مشتقّته الخاطئة** يأخذ نقاط الخطوة الثانية كاملة.

```python
@dataclass(frozen=True, slots=True)
class BaremNode:
    node_id: str
    item_id: str
    claim: str                       # "المشتقّة f'(x)"
    points: float                    # 0.5 · 0.25 كما في السلالم الرسمية
    predecessors: tuple[str, ...]
    verification: ClaimKind          # D-215
    carries_forward: bool = True     # ← قاعدة عدم العقاب المزدوج
```

### خوارزمية التقييم

```
لكل عقدة n بترتيبٍ طوبولوجي:
    إن طابق إنتاج الطالب n عند القيم الصحيحة              → منحٌ كامل
    وإلا إن كان n.carries_forward وطابق عند قيم الطالب
         الخاطئة الموروثة من سلفه                          → منحٌ كامل   ← الفرق كلّه
    وإلا                                                   → لا منح + تسجيل نمط الخطأ (D-217)
```

السطر الثالث هو ما يفصل بين نظامٍ يفهم البكالوريا الجزائرية ونظامٍ لا يفهمها. وهو أيضاً ما
يجعل التقرير **عادلاً** في نظر التلميذ — والعدالة المُدرَكة شرط بقاء المستعمل.

### المخرَج

```
النقطة المقدّرة: 11.5 / 20
  ⊖ 2.0  التمرين 2 — قابلية الاشتقاق غير مبرَّرة
  ⊖ 1.5  التمرين 3 — الوحدة غائبة
  ⊕ 1.0  التمرين 3 ب — مُنِحت رغم خطأٍ سابق (لا عقاب مزدوج)
```

السطر الأخير هو أثمن سطرٍ في التقرير: يُثبت للتلميذ أن النظام **قرأ استدلاله** لا جوابه فقط.

**قناة الالتقاط.** صورة الورقة → OCR → استخراج الخطوات → مطابقة مع عُقَد السلّم. التلميذ
الجزائري يكتب بالقلم.

**البوّابة المستقبلية:** `check_barem_item_linkage` — كل عنصرٍ بعُقَدٍ غير فارغة يجب أن
تكون عقده موجودةً وذات رسمٍ لا دوريّ، ومجموع نقاط عُقَد التمرين = نقطته المعلنة في السلّم
الرسمي، وإلّا CI أحمر.

**ما لا يجوز ادّعاؤه.** لا «نصحّح كالمصحّح الرسمي». بل: *«نطبّق السلّم المنشور للدورات
السابقة، وننشر معدّل اتّفاقنا مع تصحيحٍ بشري على عيّنةٍ مُدقَّقة.»*

**الفارض:** `check_revenue_doctrine` اليوم؛ و`check_barem_item_linkage` عند البناء.

## D-215) `shared/verify/symbolic.py` — بوّابة البرهان الرمزي

> الوحدة التي تسمح بجملةٍ لا يستطيع منافسٌ قولها: **«لا رقم يُعرَض على الشاشة لم يُعِد
> مُتحقّقٌ رمزي اشتقاقه.»**

### لماذا

بنية «Verify-then-Reply» القائمة تنتقد المسودّة بنموذجٍ لغوي ثانٍ. هذا **مكلف** (يضاعف
الاستدلال)، و**بطيء**، و**غير حتميّ** — والأعمق: نموذجٌ يخطئ في حساب قد يخطئ في التحقّق من
الحساب نفسه. **الخطأ المرتبط لا يُكتشَف بالتكرار.** والتحقّق الرمزي يحلّ الثلاثة معاً،
وهذا نادر: عادةً تُدفَع الموثوقية ثمناً للسرعة.

### العقد

```python
class ClaimKind(StrEnum):
    EQUALITY     = "equality"     # f'(x) = 2x + 3
    NUMERIC      = "numeric"      # P(A) = 14/165
    LIMIT        = "limit"
    INTEGRAL     = "integral"
    UNVERIFIABLE = "unverifiable" # نصّ تربوي — يمرّ بلا ادّعاء

class Verdict(StrEnum):
    PROVEN       = "proven"       # simplify(lhs − rhs) == 0
    REFUTED      = "refuted"      # ← يمنع العرض ويعيد التوليد
    TIMEOUT      = "timeout"      # ← يمنع العرض. لا يُعامَل كنجاح.
    OUT_OF_SCOPE = "out_of_scope"
```

### القاعدة الحديدية

```python
if claim.kind is not ClaimKind.UNVERIFIABLE and verdict is not Verdict.PROVEN:
    raise VerificationError(claim)   # لا fallback صامت — §0
```

⛔ **`TIMEOUT` ليس نجاحاً.** هذا هو الخطأ الذي ترتكبه كل الأنظمة: تعامل انتهاء المهلة
كـ«لم نجد مشكلة». في نظامٍ يخدم قاصرين قبل امتحانٍ مصيري، انتهاء المهلة يعني **لا نعرف**،
ولا نعرف تُعلَن ولا تُعرَض.

### التركيب مع القاعدة الذهبية (D-113)

⛔ **التحقّق داخليّ ولا يُعرَض.** النظام يتحقّق من `P(A) = 14/165` **كي لا يقولها**، لا كي
يقولها. المُتحقِّق يضمن أن التلميحات تقود إلى نتيجةٍ صحيحة، وقاعدةُ الحجب تضمن ألّا تُطبَع
النتيجة. الوحدتان لا تتعارضان — الأولى تخدم الثانية. **ومخرَج المُتحقِّق ممنوعٌ من الوصول
إلى طبقة العرض.**

### التغطية المستهدفة

| نوع الادّعاء | نسبة تقديرية في بكالوريا الرياضيات | قابل للتحقّق رمزياً |
|---|---|---|
| مشتقّات · حدود · تكاملات | ~40٪ | ✅ كاملاً |
| جبر · معادلات · متطابقات | ~25٪ | ✅ كاملاً |
| احتمالات · تعدادية | ~15٪ | ✅ (بأعدادٍ كسرية دقيقة) |
| هندسة تحليلية | ~10٪ | ✅ جزئياً |
| برهان استدلالي / تعليل | ~10٪ | ❌ يبقى نصّياً |

**~90٪ من الادّعاءات الرياضية قابلة للتحقّق حتمياً** — رقمٌ يُقال ويُقاس ويُنشَر.

### المقاييس

```
cogniforge_symbolic_verdicts_total{kind,verdict}
cogniforge_symbolic_duration_seconds
cogniforge_symbolic_refuted_ratio      ← يقيس جودة المولّد نفسه
```

`refuted_ratio` مزدوج الفائدة: يقيس أمان المخرجات **ويقيس جودة النموذج**؛ وارتفاعه إشارةٌ
إلى تغيّرٍ في المزوّد **قبل** أن يشتكي أيّ تلميذ.

## D-216) `shared/forecast/` — توقّع المعدّل وبطاقة المعايرة

### التوقّع: محاكاة مونت-كارلو على ورقةٍ مُركَّبة

```
لكل محاكاة k:
    ركّب ورقةً حسب البنية الرسمية للمادة (عدد التمارين، توزّع المفاهيم)
    لكل عنصر i:
        θ = mastery_to_theta(M_{concept(i)})            # من D-212
        p = g + (1 − g)·σ(a_i (θ − b_i))                # 3PL
        نتيجة_i ~ Bernoulli(p)
    score_مادة_k = Σ نقاط عُقَد السلّم المُحقَّقة        # D-214
معدّل_k = Σ_s coef_s · score_s / Σ_s coef_s              # المعاملات من shared/curriculum
```

**المخرَج توزيعٌ لا رقم:** نقطة + مجال ثقة + **أكبر ثلاث روافع** («إتقان الاتصال والاستمرار
يرفع التوقّع بـ+0.8 نقطة»). ومفهومٌ **غير مقيس** يُعرَض كرافعة، لأن عدم القياس نفسه معلومة
قابلة للتصرّف.

### بطاقة المعايرة — وهي التي لا تُنسَخ

```
BS = (1/N) · Σ (p_i − o_i)²                     # درجة Brier
BS = reliability − resolution + uncertainty      # تفكيك Murphy (1973)
#    ↓ صغّرها      ↓ كبّرها      ↓ ثابت من الطبيعة
```

التفكيك ليس ترفاً أكاديمياً: **`reliability` مرتفعة تعني توقّعاتٍ متحيّزة (قابلة للإصلاح
بالمعايرة)، و`resolution` منخفضة تعني توقّعاتٍ لا تميّز بين التلاميذ (تحتاج بياناتٍ
أكثر).** التشخيصان مختلفان تماماً، والدرجة الخام وحدها لا تفرّق بينهما.

```python
@dataclass(frozen=True, slots=True)
class CalibrationCard:
    session_year: int
    n_predictions: int
    brier_score: float
    reliability: float
    resolution: float
    uncertainty: float
    bins: tuple[ReliabilityBin, ...]   # منحنى الموثوقية
    mae_points: float                  # الخطأ المطلق بالنقاط على 20
    is_calibrated: bool                # عيّنة كافية و reliability تحت العتبة
```

### القاعدة التي تشتري المصداقية

```python
if not card.is_calibrated:
    forecast.label = "غير معايَر — الدورة الأولى"
    forecast.show_interval_only = True    # مجالٌ بلا نقطةٍ مركزية
```

⛔ **في السنة الأولى لا يُعرَض رقمٌ مركزي.** يُعرَض المجال ومعه العبارة صراحةً. هذا يكلّف
جاذبيةً بصرية ويشتري ما هو أثمن: **الوليّ الذي رأى النظام يعترف بحدوده في السنة الأولى
يصدّق رقمه في السنة الثانية.**

**البوّابة المستقبلية:** `check_forecast_calibration_label` — توقّعٌ غير معايَر يُعرَض بلا
وسمٍ صريح ⇒ CI أحمر.

**الفارض:** `check_revenue_doctrine` اليوم؛ و`check_forecast_calibration_label` عند البناء.

## D-218) `shared/planning/optimizer.py` — مُحسِّن الوقت المتبقّي

### الصياغة

```
عظّم:    Σ_c  coef(c) · ∂E[معدّل]/∂M_c · ΔM_c(t_c)
بشرط:    Σ_c t_c ≤ B                    (الميزانية اليومية)
         t_c ∈ {0} ∪ [t_min, t_max]
```

**ثلاثة مدخلات:** `coef(c)` من `shared/curriculum.STREAM_COEFFICIENTS` (قائم) ·
`∂E[معدّل]/∂M_c` فرقٌ منتهٍ على D-216 · `ΔM_c(t_c)` من FSRS القائم (العائد من مراجعة الآن
مقابل لاحقاً).

### الحلّ: جشعٌ بكثافة القيمة (لا برمجة خطية)

```
ρ_c = coef(c) · ∂E/∂M_c · ΔM_c / t_c      # عائد لكل دقيقة
رتّب تنازلياً حسب ρ، وخذ حتى استنفاد B
```

الجشع كافٍ لأن الدالّة تقريباً غاطسة (تناقص العائد الحدّي للمراجعة)، **والتلميذ لا يحتمل
انتظار حلٍّ أمثل**. البساطة قرارٌ لا تنازل.

### قيدان تربويان إجباريان

```python
MAX_CONSECUTIVE_SAME_CONCEPT = 2     # التشبيك — Rohrer & Taylor (2007)
MIN_DAILY_MINUTES = 10               # الحدّ الأدنى صغيرٌ عمداً — D-220
```

⛔ القيد الأول ليس تجميلاً: الجشع الخام يكدّس كل الوقت على مفهومٍ واحد عالي المعامل، وهو
**بالضبط النمط الكتليّ الذي تُثبت الأدبيات أنه أسوأ من التشبيك**. **مُحسِّنٌ بلا هذا القيد
يعظّم رقماً ويهدم التعلّم.**

### المخرَج — وهو جملةٌ تُباع

```
اليوم · 40 دقيقة
  25 د   الاتصال والاستمرار
         ستنساه خلال 6 أيام · معامله 5 · +0.8 نقطة متوقّعة
  15 د   الحمض والأساس
         أنت واثقٌ فيه وأنت مخطئ 🔴 · معامله 5
```

**البوّابة المستقبلية:** `check_optimizer_constraints` — أي مسارٍ يُنتج خطّةً تخرق
`MAX_CONSECUTIVE_SAME_CONCEPT` أو تتجاوز الميزانية ⇒ CI أحمر.

**الفارض:** `check_revenue_doctrine` اليوم؛ و`check_optimizer_constraints` عند البناء.

## الخيط الجامع

الطبقات كلّها تبني شيئاً واحداً: **تاريخاً مقيساً لتلميذٍ جزائري بعينه** — بلغته، ووفق
سلّم تنقيطه، ومعامل شعبته، ومنحنى نسيانه.

- ‏D-213 يعطي **ما يُقاس به**
- ‏D-212 وD-215 يعطيان **قياساً صادقاً**
- ‏D-214 وD-216 يترجمانه إلى **لغة الوليّ**
- ‏D-218 يترجمه إلى **فعل**
- ‏D-211 وD-221 يترجمانه إلى **دينار**
- ‏D-217 وD-222 يجعلانه **يتراكم**

وهذا التاريخ هو الشيء الوحيد الذي لا يستطيع رأسمالٌ ضخم شراءه، ولا نموذجٌ لغوي عام إنتاجه.
