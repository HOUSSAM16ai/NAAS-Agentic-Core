

## شرح تمرين الدوال العددية 2016 — الدورة الأولى

### السياق الكامل

**الدالتان الأساسيتان:**
- \\(g(x) = 1 + (x^2+x-1)e^{-x}\\) على \\(\mathbb{R}\\)
- \\(f(x) = -x + (x^2+3x+2)e^{-x}\\) على \\(\mathbb{R}\\)
- \\(h(x) = x + f(x) = (x^2+3x+2)e^{-x}\\)
- \\(H(x) = (ax^2+bx+c)e^{-x}\\) الدالة الأصلية لـ \\(h\\)

**النتائج الرئيسية:**
- \\(f'(x) = -g(x)\\) — العلاقة الجوهرية بين الدالتين
- \\(a = -1,\ b = -5,\ c = -7\\)
- \\(H(x) = (-x^2-5x-7)e^{-x}\\)
- \\(A(\lambda) = (-\lambda^2-5\lambda-7)e^{-\lambda} + 7\\)
- \\(\lim_{\lambda \to +\infty} A(\lambda) = 7\\)

### نقاط الانعطاف

$$A(-1;\ 1) \quad \text{و} \quad C\!\left(2;\ -2+\frac{12}{e^2}\right)$$

### المستقيم المقارب

$$(\Delta): y = -x \quad \text{مقارب مائل عند } +\infty$$

## قواعد اللغة والتنسيق

### الاتجاه

- النص العربي: من اليمين لليسار دائماً
- الرموز الرياضية: تُعرض بشكل مستقل (لا تتأثر بالاتجاه)
- الجداول: تُكتب بالعربية مع الرموز LaTeX

### مستوى الشرح

- **للطالب المبتدئ:** اشرح كل خطوة بالتفصيل، اذكر القاعدة الرياضية المستخدمة
- **للطالب المتوسط:** اشرح الخطوات الحرجة، أجمل الخطوات البسيطة
- **للطالب المتقدم:** ركز على النقاط الصعبة والتفسير الهندسي

### الأخطاء الشائعة التي يجب التنبيه عليها

1. **نسيان أن \\(e^{-x} > 0\\) دائماً** → إشارة \\(f'(x)\\) تتبع إشارة \\(-g(x)\\) فقط
2. **الخلط بين المقارب المائل والأفقي** → \\(y = -x\\) مائل، ليس أفقياً
3. **نسيان التحقق من تغيير إشارة \\(f''\\)** عند نقاط الانعطاف
4. **الخلط بين الدورة الأولى والثانية لـ 2016**

## نموذج الرد المثالي

عندما يسأل الطالب: "اشرح لي الجزء II-(1)-ب من تمرين الدوال العددية 2016 الدورة الأولى"

```
## إثبات أن f'(x) = -g(x)

**المبدأ:** نشتق f(x) باستخدام قاعدة الضرب (uv)' = u'v + uv'

**الدالة:**
$$f(x) = -x + (x^2+3x+2)e^{-x}$$

**الاشتقاق:**
نضع: u = x²+3x+2 و v = e^{-x}

فنجد: u' = 2x+3 و v' = -e^{-x}

$$f'(x) = -1 + (2x+3)e^{-x} + (x^2+3x+2)(-e^{-x})$$

$$= -1 + \left[(2x+3) - (x^2+3x+2)\right]e^{-x}$$

$$= -1 + (-x^2-x+1)e^{-x}$$

$$= -\left[1 + (x^2+x-1)e^{-x}\right]$$

$$\boxed{f'(x) = -g(x)} \checkmark$$
```
