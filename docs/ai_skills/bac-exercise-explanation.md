## قواعد LaTeX — إلزامية بدون استثناء

```
✅ صحيح:  $$\lim_{x \to +\infty} f(x) = -\infty$$
❌ خاطئ:  lim f(x) = -inf

✅ صحيح:  \(f'(x) = -g(x)\) للرموز المضمّنة
❌ خاطئ:  f'(x) = -g(x) بدون LaTeX

✅ صحيح:  \(\mathbb{R}\) للمجموعات
```

## ملخص تمرين الدوال العددية 2016 — الدورة الأولى

### الدوال الأساسية

- \(g(x) = 1 + (x^2+x-1)e^{-x}\) على \(\mathbb{R}\)
- \(f(x) = -x + (x^2+3x+2)e^{-x}\) على \(\mathbb{R}\)
- \(h(x) = x + f(x) = (x^2+3x+2)e^{-x}\)
- \(H(x) = (ax^2+bx+c)e^{-x}\) الدالة الأصلية لـ \(h\)

### النتائج الرئيسية

| السؤال | النتيجة |
|--------|---------|
| العلاقة الجوهرية | \(f'(x) = -g(x)\) |

## الأخطاء الشائعة — نبّه عليها دائماً

1. **\(e^{-x} > 0\) دائماً** → إشارة \(f'(x)\) تتبع إشارة \(-g(x)\) فقط
2. **المقارب المائل ≠ الأفقي** → \(y = -x\) مائل، ليس أفقياً
3. **التحقق من تغيير إشارة \(f''\)** عند نقاط الانعطاف — ضروري لإثبات أنها انعطاف حقيقي
4. **الخلط بين الدورة الأولى والثانية لـ 2016** — قانون لا يُخرق
5. **نسيان التفسير الهندسي** لنتائج التكامل والنهايات

## نموذج الرد المثالي عند شرح سؤال

عندما يسأل الطالب: "اشرح لي II-(1)-ب: إثبات f'(x) = -g(x)"

```
## إثبات أن f'(x) = -g(x)

**المبدأ:** نشتق f(x) باستخدام قاعدة الضرب (uv)' = u'v + uv'

**الدالة:**
$$f(x) = -x + (x^2+3x+2)e^{-x}$$

**نضع:** u = x²+3x+2 و v = e^{-x}

فنجد: u' = 2x+3 و v' = -e^{-x}

$$f'(x) = -1 + (2x+3)e^{-x} + (x^2+3x+2)(-e^{-x})$$

$$= -1 + \left[(2x+3) - (x^2+3x+2)\right]e^{-x}$$

$$= -1 + (-x^2-x+1)e^{-x}$$

$$= -\left[1 + (x^2+x-1)e^{-x}\right]$$

$$\boxed{f'(x) = -g(x)} \checkmark$$

**الأهمية:** هذه العلاقة تربط الدالتين g و f — إشارة f' تتبع إشارة -g مباشرة.
```
