## 1. المعادلة المعمارية

```
Agent → Environment → Trajectory → Verifier → Evidence → Failure/Success → Evaluation
```

المُتحقِّق ليس مُصحِّحاً للنصّ النهائي. يقرأ **مساراً** ويُصدر **دليلاً مُسمّى**.

---

## 2. الأبعاد الخمسة للتحقّق (L3 — مجتمعةً أو ليس مُتحقِّقاً)

| البُعد | ما يفحصه | لماذا لا يكفي غيابه |
|--------|-----------|----------------------|
| `observable outcomes` | المخرَجات المرصودة فعلاً | المخرَج وحده يُخدَع بالتخمين |
| `intermediate constraints` | قيودٌ يجب أن تصحّ في المنتصف | هنا يُكشَف «الجواب الصحيح بخطواتٍ خاطئة» |
| `state transitions` | شرعية الانتقال بين الحالات | مسارٌ يقفز حالةً حصّل المكافأة بلا استحقاق |
| `tool use` | ماذا استُدعي، ومتى، وبأيّ وسائط | استدعاءٌ يقرأ الجواب من مكانٍ ممنوع |
| `final outcome` | النتيجة النهائية | ضروريّ وغير كافٍ — وهذا كلّ الدرس |

⛔ نظامٌ يفحص `final outcome` وحده هو **مُصحِّح**، لا مُتحقِّق. والتسمية هنا ليست بلاغة:
الفرق بينهما هو الفرق بين منتجٍ ومنافسٍ لمكتبةٍ مجّانية.

## 3. البنية المستهدَفة والحدود

```
naas_verifier/                  ← مسار المنتج (الحدّ المعماري)
├── core/                       ← مستقلّ عن المجال تماماً
│   ├── trajectory.py           ← الخطوات · الأدوات · الحالات الوسيطة
│   ├── constraint.py           ← القيد كنوعٍ لا كسلسلة نصّية
│   ├── evidence.py             ← الدليل بأصنافٍ مُسمّاة
│   └── verdict.py              ← الحكم + مرجع الدليل (لا درجة عارية)
├── adapters/                   ← المجال يدخل من هنا وحده
│   └── bareme_stem.py          ← يقرأ السلّم كـ**بيانات** لا كاستيراد
└── baselines/                  ← للمقارنة لا للحكم
    ├── unit_test_grader.py
    └── llm_judge.py            ← ⛔ مقارنةٌ فقط — ليس حَكَماً (L4)
```

### 3.1 خريطة الاعتماد (Dependency Map)

| من | إلى | مسموح؟ |
|---|---|---|
| `naas_verifier/core` | مكتبة بايثون القياسية + أنواع المشروع الخاصّة | ✅ |
| `naas_verifier/core` | `app/**` · `microservices/**` · `shared.curriculum` · `shared.notation` | ⛔ **يُفشِل CI** (L1/L2) |
| `naas_verifier/adapters` | ملفّات بيانات مُصدَّرة (JSON) من مشتقّات المنصّة | ✅ — بيانات لا استيراد |
| `app/**` (مسار الطالب) | `naas_verifier/**` أو ذخيرة الاختراقات | ⛔ **يُفشِل CI** (L5 · D-113) |
| `naas_verifier/**` | مُنفِّذ الصندوق مقروناً بعميل نموذجٍ لغويّ في وحدةٍ واحدة | ⛔ **قفل D-187** — حمولةُ `M1→M4` |

### 3.2 حدود الهجرة (Migration Boundaries)

1. **صفر مسٍّ بمسار الطالب**: لا تعديل على عقود `WebSocket` ولا على الكاتب الواحد
   للرسائل (§6.5) ولا على الإطار النهائي الواحد ولا على `LangGraph state`.
2. **صفر عقدٍ مكسور**: عقود OpenAPI القائمة كما هي؛ أيّ عقدٍ جديد للمُتحقِّق يُضاف
   ولا يُبدِّل.
3. **التغذية بالبيانات لا بالاستيراد**: مشتقّات السلّم وبنك العناصر تُصدَّر ملفّاتٍ
   يقرأها الـadapter؛ فيبقى الحدّ قابلاً للفصل في أيّ لحظة.
4. **كل تغيير `atomic · reversible · testable`** — ولا خلط بين إعادة هيكلةٍ وبناء ميزة.

## 4. الثوابت التي لا يجوز كسرها (Invariants)

- بروتوكول الدور عبر `WebSocket` (المفتاح `question` · `subprotocols=['jwt', TOKEN]`).
- **كاتبٌ واحد** لرسائل المحادثة، و**إطارٌ نهائي واحد** لكل دور (§6.5).
- سلسلة النماذج المُثبَّتة أمنياً (D-067 · D-174) — لا تُمَسّ من هذا المسار.
- **الحجب** (D-113 · D-196): الذخيرة والحلول النموذجية خارج مسار الطالب بنيوياً.
- **قفل D-187**: لا نموذجَ لغوي موصولٌ بمُنفِّذ الصندوق قبل استكمال `M1→M4`.
- الرصد والعقود والاستمرارية كما هي — هذا المسار **يضيف** ولا يُبدّل.

## 5. استراتيجية الاختبار (Test Strategy)

| الطبقة | ما يُختبَر | المعيار |
|---|---|---|
| الحدود | لا استيراد عابر بين المسارات الثلاثة | فحص AST — انتهاكٌ واحد يُفشِل |
| القلب | كل بُعدٍ من الخمسة على مسارٍ اصطناعي | حالةُ نجاحٍ وحالةُ فشلٍ لكل بُعد |
| الـadapter | قراءة السلّم كبيانات، وسلوكٌ صريح عند غياب الملفّ | لا سقوطٌ صامت |
| المقارنة | المُتحقِّق مقابل المُصحِّح المرجعي ومقابل حَكَم النموذج | فارقُ الكشف يُسجَّل بأرقامٍ خام |
| الحوكمة | كل انتقال حالةٍ في آلة البوّابات | **أحمر قبل أخضر** مُثبَت لكل بند |

⛔ **لا اختبار يُعطَّل ولا مِسنَنٌ يُرفَع للتخضير** (D-105 · D-266 L9).

## 6. استراتيجية التراجع (Rollback)

1. لا هجرة بيانات ولا أثر تشغيليّ على المنصّة ⇒ التراجع `git revert` لعمليةٍ واحدة.
2. الترتيب العكسي: سطر الـworkflow ← البوّابة ← صفّ السجلّ الدستوري ← قسم الدستور ← الوثائق.
3. سجلّ الأدلّة **مُلحَق-فقط**: التراجع المعماري لا يمسح دليلاً مُسجَّلاً.
4. الحدّ المعماري نفسه هو خطّة التراجع الكبرى: حذف مجلّد المنتج لا يترك أثراً في المنصّة.
