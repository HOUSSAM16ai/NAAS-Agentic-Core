## Why
There was an untested factory function `get_cache()` in `app/caching/factory.py` that acted as a main wrapper for the `CacheFactory`. Adding tests increases test coverage and ensures regressions don't break default behavior.

## Summary
- Added `test_get_cache_returns_memory_cache_by_default` to ensure default in-memory fallback.
- Added `test_get_cache_returns_redis_cache_when_configured` to check the Redis branch and parameter passing.
- Added `test_get_cache_singleton_behavior` to verify object identity.
