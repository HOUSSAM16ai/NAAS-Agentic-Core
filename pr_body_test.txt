## Summary
Removed the empty `pass` loop in `_rollback_faults` and replaced it with a `NotImplementedError` and a `TODO` comment.

## Why
The previous code had a misleading log stating it was rolling back faults, followed by an empty loop. We checked the codebase and found no existing rollback/revert mechanisms for faults. Instead of silently leaving faults active after an experiment ends (which is a functional bug), the code now fails loudly with `NotImplementedError` to clearly flag that this functionality needs to be built.

## How to Test
1. Check out this branch.
2. Run the temporary test script that checks if `NotImplementedError` is raised when `_rollback_faults` is called on a `ChaosEngineer` instance.
```bash
cat << "EOF" > test_chaos_local.py

    engineer = ChaosEngineer()
```
